# Included And Required Files

The computer-side `PREPARE-GAME.py` helper is included under
[MIT](CHECK-FILES-LICENSE.txt). It downloads an unmodified, checksum-pinned
nodtool directly from its [official release](https://github.com/encounter/nod/releases/tag/v2.0.0-alpha.12).
The downloaded extractor stays on the user's computer; it is not a game asset.
The local install bundle includes the reviewed source, preparation tools,
all linked guides and notices alongside the unchanged private VPK.

The release should include the matching player executable, app metadata,
permitted original release artwork, boot resources, matching shader resources
and all required source/notices. Their final inventory is not approved yet.

The read-only device recovery includes the current executable, boot image,
shader pack and shader list. Installed artwork and installation-generated
package records remain private audit inputs, not automatically licensed
release files. The installed fan art has no recorded redistribution grant.

Supply your own supported game dump. Extracted retail data, music, movies,
logos, saves, NAND contents and test profiles are not included. A code
license does not grant rights to the original game assets.

Useful screenshots will be added only when their source, build, sharing
basis and privacy review are established. No borrowed promotional images or
emulator shots presented as Vita performance proof are included here.
