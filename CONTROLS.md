# Controls

The native player defaults to **Modern**. A **Classic** layout is also
available in the game's control settings; its full mapping still needs
checking against the current source export.

| Vita Input | Modern Action |
| --- | --- |
| Cross | Pass / switch player |
| Circle | Shoot / slide tackle |
| Square | Lob / big hit |
| Triangle | Use item |
| R | Chip ahead / action modifier |
| L | Switch player |
| Right stick or D-pad | Deke |
| Select or rear-left tap | Cycle items |
| Rear-right tap | Switch player |

## Camera

Go to **Options > Visual**. Select level 5, then press its button again to
cycle **5 -> 6 -> 7 -> 5**. The label shows the selected level. Auto Zoom
still moves the camera with play. Levels 6 and 7 are closer views; the
computer team's visibility is widened so the closer camera does not simply
hide passing and item opportunities from it.

Existing saves keep their camera choice until changed. The Options cycle,
level 6 gameplay, rear touch and final-package settings persistence still
need current Vita acceptance. Front touch, motion, PS TV and external
controller behavior are not verified by this guide.
