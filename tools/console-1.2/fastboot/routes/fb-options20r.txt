# fast boot (test only, front20): OPTIONS -> VITA SETTINGS -> SMOOTH 60 changed (a next-start row) -> DONE: the popup SAVE AND START AGAIN / DON'T SAVE / KEEP EDITING -> Circle (stays) -> DONE -> SAVE AND START AGAIN: the file is written and the game starts again.

# Run: emu.sh <tag> <vpk> env/fb-options20r.txt <seconds> <this file>.

log first run: no save file, accepting 'create save data'
wait nbuttons >= 2
idle 10

wait nbuttons >= 8
endif
wait onctx == 0
log STATE main menu
idle 120
touch 398 455 4 30
wait scene == 13 900
log STATE options scene
idle 150
log STATE corner button
touch 480 497 4 30
wait scene == 88 900
idle 250
touch 480 223 4 40
idle 30
log STATE smooth 60 changed (a next-start row)
touch 480 418 4 30
idle 120
log STATE leave popup (SAVE AND START AGAIN / DON'T SAVE / KEEP EDITING)
vpress circle 3 60
idle 120
if scene == 88
log STATE KEEP EDITING kept the screen
endif
touch 480 418 4 30
idle 120
vpress cross 3 60
log STATE SAVE AND START AGAIN pressed
idle 600
